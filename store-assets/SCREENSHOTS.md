# Capturas para Play Store

Play pide **mínimo 2**. Sube **6** de **Cuenta Real con contrato mainnet vivo**.

Las fotos de QA en `.expo/live-*.png` **no sirven** si muestran Demo, «Pronto» o el lanzador de Expo.

## Prohibido en la imagen

- Frase de 24 palabras o QR de recuperación
- Panel Admin / fundadoras
- Banner de Metro / Dev Client
- Correo o teléfono de un tercero
- Texto «Pronto» en el nivel 1

## Orden recomendado (vertical 9:16)

1. Hub Real — crédito y acceso ya pagado
2. Niveles con gemas (no digas 10 niveles)
3. Red + Copiar código
4. Historial con las tres ventanas
5. Seguridad / candado **sin** abrir la frase
6. Donar o pool con el aviso de que el pool no se retira

## Tamaño

- PNG o JPG, sin transparencia
- Lado corto ≥ 320 px; lado largo ≤ 3840 px
- ≤ 8 MB cada una
- Feature graphic: `feature-graphic.png` (1024×500)
- Icono tienda: `play-icon-512.png` (512×512)
